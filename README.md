#HejSvenskaTestBlazor

A small Blazor practice project created as preparation for my LIA internship with the Hej Svenska WebApp project.

The purpose of this project is to practice the Blazor concepts and technologies that will be relevant during my LIA.

##About the project

The application displays Swedish learning topics and words. Each topic contains words with an image, description and audio.

The project uses JSON files as the data source and does not use a database or authentication.

##Technologies
-C#
-.NET / Blazor
-Blazor Interactive Server
-Razor components
-JSON
-HTML / CSS


##What I have practiced

-Blazor components and Razor syntax
-Parent and child components
-Component parameters with [Parameter]
-Dependency Injection
-Services and interfaces
-Loading data asynchronously
-Reading data from JSON
-Blazor routing and route parameters
-Event handling with @onclick
-Working with images and audio
-Basic component-based application structure

##The application contains:

-Topics – displays the available learning topics
-TopicDetails – displays the words belonging to a selected topic
-WordCard – reusable component for displaying individual words
-TopicService – handles loading topic data from JSON
-topics.json – contains the learning content
